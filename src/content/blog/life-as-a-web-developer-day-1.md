# Life as a Web Developer - Day 1

Every journey begins somewhere, and today marks another step in my journey toward becoming a web developer.

Learning web development is something I've wanted to explore more deeply. The idea of creating something from scratch, turning ideas into functional websites, and understanding how everything works behind the scenes is both exciting and challenging.

This is where I begin documenting that journey.

## Starting with the Basics

One of the first things I am learning is that web development involves more than just writing code.

It requires patience, creativity, problem-solving, and a willingness to keep learning.

There are several technologies that every aspiring web developer should become familiar with:

- **HTML** – The foundation and structure of a website.
- **CSS** – The language used to style and design web pages.
- **JavaScript** – Adds functionality and interactivity to websites.
- **Astro** – A modern web framework that helps build fast, content-focused websites.
- **Git and GitHub** – Tools for tracking code changes and managing projects.

Each technology has its own purpose, and understanding how they work together is an important part of becoming a developer.

## Building My First Blog Website

One of the exciting parts of this journey is working on my own website, The Gray Journal.

I'm building it using the Astro framework and learning how to organize pages, create reusable layouts, manage blog content, and improve website performance.

So far, I've started working on:

- Creating the homepage.
- Designing a clean and minimalist interface.
- Implementing a dark and light theme.
- Setting up a blog content collection.
- Creating individual blog article pages.
- Learning how to manage changes using Git.

It's a great feeling to see something I worked on actually running in a browser.

Of course, there are still errors to fix and many things to improve, but that's part of the learning process.

## Challenges Along the Way

One thing I've realized is that coding doesn't always go as planned.

Sometimes a small mistake can prevent an entire page from working. Other times, something appears correct visually but produces errors in the browser console.

I've learned that understanding errors is just as important as writing code.

Instead of getting discouraged, I'm trying to approach every problem as an opportunity to learn something new.

## What I Want to Achieve

My goal is to become more confident in building websites and eventually develop projects that are useful, functional, and enjoyable to use.

I also want to document my progress through this blog.

By keeping track of what I learn each day, I can look back and see how much I've improved over time.

## Final Thoughts

Day 1 is not about knowing everything.

It's about starting, experimenting, making mistakes, and being willing to learn.

There is still a long way to go, but every line of code brings me one step closer to becoming a better developer.

**This is just the beginning. More lessons, projects, and experiences coming soon.**

Thanks for being part of my journey!
